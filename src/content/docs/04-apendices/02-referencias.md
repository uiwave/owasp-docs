Este apéndice recoge las referencias del ASVS 4.0.3: los proyectos OWASP y sitios externos más útiles para quienes adoptan o verifican el estándar.

## Principales proyectos OWASP

1. **OWASP Top 10 Project:** https://owasp.org/www-project-top-ten/
2. **OWASP Web Security Testing Guide:** https://owasp.org/www-project-web-security-testing-guide/
3. **OWASP Proactive Controls:** https://owasp.org/www-project-proactive-controls/
4. **OWASP Security Knowledge Framework:** https://owasp.org/www-project-security-knowledge-framework/
5. **OWASP Software Assurance Maturity Model (SAMM):** https://owasp.org/www-project-samm/

## OWASP Cheat Sheet Series

Este proyecto tiene una serie de hojas de trucos relevantes para distintos temas del ASVS. Existe un mapeo entre las cheat sheets y el ASVS, disponible en:

- https://cheatsheetseries.owasp.org/cheatsheets/IndexASVS.html

## Referencias por capítulo

Cada capítulo del sitio incluye sus propias referencias específicas. Las más recurrentes a lo largo del estándar son:

- **OWASP Testing Guide 4.0** (y Web Security Testing Guide 4.1) — pruebas de autenticación, sesiones, autorización, validación de entrada, manejo de errores, configuración, lógica de negocio y verbos HTTP.
- **OWASP Cheat Sheets** — Session Management, Authentication, Access Control, CSRF, XXE Prevention, REST Security, Cryptographic Storage, Third Party JavaScript Management, Content Security Policy, User Privacy Protection.
- **OWASP AppSensor** — detección de ataques y respuesta.
- **OWASP Automated Threats to Web Applications** — amenazas automatizadas.
- **OWASP Cornucopia** — modelado de amenazas en sprints de diseño.
- **OWASP Serverless Top 10** — seguridad de funciones serverless.
- **OWASP Internet of Things Top 10** y **OWASP Embedded Application Security Project** — seguridad de dispositivos embebidos.
- **Mozilla Server Side TLS** — guías de configuración segura de TLS.
- **FIPS 140-2** — módulos criptográficos validados.
- **GDPR (UE)** y **Principios de Privacidad de Australia (APP-11)** — privacidad de datos.
- **Detectify Labs** — Hostile Subdomain Takeover y Hijacking of abandoned subdomains.
